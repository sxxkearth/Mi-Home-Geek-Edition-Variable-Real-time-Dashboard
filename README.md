本脚本为米家极客版自定义变量实时监控工具，基于 Tampermonkey（篡改猴/油猴）开发，专为米家极客版网页调试、变量监测、逻辑排错设计。可以实时抓取页面所有全局/非全局自定义变量，自动监测变量数值变动，可视化展示变量状态，极大提升米家自动化调试效率。
脚本支持窗口自由拖拽、双向缩放、尺寸自适应、列数动态适配，全程免配置，安装即用，是米家极客版进阶玩家、开发者必备调试工具。
核心功能特点
- ✅ 全量变量抓取：自动读取米家极客版所有全局变量、局部非全局变量，完整罗列展示，无遗漏。
- ✅ 变量变动高亮提醒：数值发生变化的变量自动红色高亮文字、深色背景标记，一眼识别变动数据，方便调试逻辑触发条件。
- ✅ 智能自适应布局：面板尺寸、表格列数跟随窗口大小、手动缩放实时自动变化，拉大自动多列、缩小自动合并列，布局永远适配屏幕。
- ✅ 自由拖拽+双向缩放：顶部标题栏可任意拖动悬浮窗口；左下角、右下角双角拖拽缩放窗口大小，支持自定义任意尺寸。
- ✅ 首次打开自适应屏幕：脚本初始化自动适配浏览器可视区域，默认居中大屏展示，无需手动调整。
- ✅ 高频实时刷新：800ms 高频轮询刷新变量数据，实时同步最新变量状态，延迟极低。
- ✅ 变量分类展示：严格区分「全局变量」和「非全局变量」，数字变量优先排序，结构清晰，方便查阅。
- ✅ 边界安全限制：窗口缩放、拖动带最大/最小边界限制，不会拖出屏幕、不会窗口塌陷，使用稳定。
- ✅ 轻量化无冲突：纯前端脚本，不篡改原有项目逻辑，不影响米家极客版正常运行，安全无副作用。
使用方法
1. 安装 Tampermonkey 浏览器扩展（篡改猴/油猴）。
2. 导入本脚本并启用，确保脚本处于开启状态。
3. 打开米家极客版网页，页面右下角会出现【变量看板】悬浮按钮。
4. 点击按钮即可打开/关闭变量监控面板。
5. 拖拽顶部标题栏可移动窗口，拖拽左下角/右下角可自由缩放窗口。
6. 缩放窗口时列表列数会实时自动适配，无需手动设置。

适配场景
- 米家极客版自动化逻辑调试、变量状态排查
- 判断变量是否正常赋值、是否触发更新
- 多变量联动场景监测、设备状态同步校验
- 新手学习变量机制、老手快速排错提速
- 脚本同时适配手机版使用；
